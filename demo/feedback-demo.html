🎨 Adaptive UI Feedback System

This demo showcases the FeedbackPopup component from the Aura Adaptive UI library. The component automatically adapts to user preferences and collects valuable feedback for the Reinforcement Learning optimization engine.

Component Features

  • Fully adaptive to user preferences (theme, font size, contrast)
  • Three feedback types: Positive, Neutral, Negative
  • 5-star rating system
  • Optional text comments
  • Backend API integration
  • Accessibility optimized (keyboard nav, ARIA labels)
  • Reduced motion support
  • High contrast mode
